# MediFirst

**Live demo here** : https://medifirst.streamlit.app/

MediFirst is an AI-powered First-Aid & Health Triage Assistant built with Python, Streamlit, and the Google Gemini API.
The project helps users perform an initial assessment of health complaints through a conversational approach. MediFirst gathers relevant information, asks clarification questions, assesses potential warning signs, and provides appropriate initial guidance.

**Features** :
  - Conversational AI health assistant
  - Step-by-step symptom clarification
  - Safety-focused health triage
  - Health concern classification: Low Concern, Attention, and Emergency
  - Interactive web interface with Streamlit

**Learning Outcomes**
Through this project, I learned and practiced:
 - Integrating the Google Gemini API with Python
 - Building an interactive chatbot using Streamlit
 - Managing conversation state with st.session_state
 - Using environment variables for API credentials
 - Designing structured system instructions for AI
 - Building a conversational AI workflow focused on safety
